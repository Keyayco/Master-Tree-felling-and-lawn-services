# Master Tree Felling and Lawn Services — Vanilla Website

A self-contained rebuild using only HTML, CSS, JavaScript, and local image assets.

## Open it
1. Unzip the folder.
2. Open `index.html` directly in any modern browser.
3. No Node.js, npm, build step, or server is required.

## Edit it
- Update page content in `index.html`.
- Update colors, layout, typography, and responsive behavior in `style.css`.
- Update navigation, service cards, reveal animations, mobile menu, and form success behavior in `script.js`.
- Replace images inside `assets/` and update the relative paths if desired.

The quote form is intentionally frontend-only: it shows a success state but does not claim to store or transmit submissions. Connect the submit handler in `script.js` to a backend or form provider when ready.
